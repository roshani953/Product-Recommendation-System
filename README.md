#Product Recommendation System

https://recommendation-syst.streamlit.app/

A Python-based Product Recommendation System that uses customer data, rating patterns and machine learning to generate relevant product recommendations through an interactive Streamlit application.

##Project Overview
The project aims to help users discover relevant products using a recommendation system built with Python.
The Application provides an interactive interface where users can select a recommendation type and enter a Product ID or USER ID to retrieve recommendations.

##Objectives

* Build an interactive product recommendation application.
* Analyse customer and product-related data.
* Generate relevant product recommendations.
* Use Machine Learning for customer segmentation.
* Display product ratings and recommendation scores.

##Technologies Used

* Pyhton
* Pandas
* Numpy
* Scikit-learn
* Pickle
* Streamlit
* Google Collab

##Key-Features

* Interactive Streamlit interface.
* Product ID and User ID selection.
* Product recommendations.
* Average rating display.
* Rating count display.
* Recommendation score display.
